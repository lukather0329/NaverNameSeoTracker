## 1. 오늘 세션에서 한 일 (요약)

### 1-1. 네이버 API 중단 이슈 파악 및 영향 범위 확인
- 네이버가 "API 중단"을 한 것은 순위 추적(크롤링성) 부분이며, 어제까지 작업한 커머스 API
  (상품 동기화, SEO 제목 전송)는 별개 API 패밀리라 영향 없음을 코드로 확인함.
- 순위 조회는 apps/server/src/providers/naver-shopping-rank-provider.ts가
  openapi.naver.com/v1/search/shop.json(네이버 검색 오픈API)을 페이지 넘겨가며 직접 스캔하는
  방식이었고, 이게 판다랭크류 도구가 단속당하는 패턴과 동일함을 확인.
- rank-provider.ts에 이미 RankProvider 인터페이스(kind: MOCK/NAVER_SHOPPING/FUTURE_API)가
  있어서 데이터 소스 교체 자체는 아키텍처상 준비되어 있음.
- 순위 데이터를 앞으로 어디서 가져올지(수동 입력 / 저빈도 완화 / 판매지표로 프록시 전환 /
  유료 데이터 제공업체)는 아직 결정 안 됨 — 다음 세션에서 결정 필요.

### 1-2. AI SEO Engine Core v0.1 신규 패키지 개발 (오늘의 메인 작업)
사용자가 ChatGPT 자문을 바탕으로 작성한 상세 개발 지시서에 따라 진행함. 핵심 원칙:
UI 먼저 안 만듦, 신규 크롤러 안 만듦, 기존 NaverNameSeoTracker 코드 대규모 수정 안 함,
독립 엔진 패키지로 개발, 점수는 항상 "네이버 공식 점수 아닌 내부 추정치"로 명시, 규칙 기반과
LLM 기반 분리, LLM 없이도 기본 분석 가능하게 설계.

- 위치: packages/ai-seo-engine/ (npm workspaces, 패키지명 @makeware/ai-seo-engine)
- 완전 구현: Semantic Analyzer, Content Quality Analyzer, Experiment Manager,
  Ranking Change Detector
- 인터페이스만 설계(미구현): Review Intelligence, Authority Score, Monte Carlo Predictor
  (Monte Carlo Predictor는 기존 rw_decision_engine과 연결하는 것을 염두에 두고 설계함)
- 공통 결과 타입 AnalysisResult<TDetails>: score/grade/confidence(점수와 별개 신뢰도)/
  summary/strengths/weaknesses/recommendations/details/metadata 구조로 모든 엔진이 통일됨.
- 점수 가중치는 하드코딩 아닌 ScoringConfig로 외부 교체 가능.
- LLM은 LlmProvider 인터페이스로 추상화 (MockLlmProvider, NoopLlmProvider만 우선 제공,
  실제 Anthropic/OpenAI 연동은 아직 없음. API 키를 엔진 내부에 저장하지 않는 설계).
- 테스트: vitest 59개 전부 통과 (Semantic 13 / Content 13 / Experiment 12 / Ranking 12 /
  공통 점수 계산 9 — 전부 지시서의 최소 요구치 이상).
- README.md에 지시서가 요구한 12개 항목 전부 작성함(설치법/사용예시/각 엔진 설명/점수산정방식/
  confidence 설명/LLM 없이 쓰는 법/LLM Provider 추가법/NaverNameSeoTracker 연결법/향후 계획 등).
- 아직 NaverNameSeoTracker apps/server와 실제로 연결하는 코드는 작성 안 함(이번 범위 제외,
  라이브러리 자체 완성이 목표였음).

## 3. 로컬 개발 환경 재기동 방법

가장 쉬운 방법: 저장소 루트의 서버_실행.exe를 더블클릭 (cmd 창 없이 몬테카를로 엔진 + 트래커
서버/웹을 백그라운드로 전부 띄워줌, 이미 켜져 있으면 자동으로 건너뜀). 로그는
D:\Codex\NaverNameSeoTracker\logs\ 아래에 남음.

수동으로 하려면:
```bash
# 1) 몬테카를로 의사결정 엔진 (별도 저장소)
cd D:\Claude\MonteCarloDecisionEngine
.venv/Scripts/python.exe -m uvicorn rw_decision_engine.api.app:app --host 127.0.0.1 --port 8765

# 2) 이 저장소 - 서버 + 웹
cd D:\Codex\NaverNameSeoTracker
npm run dev
```

ai-seo-engine 패키지만 따로 확인하려면:
```bash
cd packages/ai-seo-engine
npm run build   # tsc --noEmit
npm run test    # vitest run
```
