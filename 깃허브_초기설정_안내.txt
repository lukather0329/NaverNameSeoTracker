1. 현재 상태
- D:\Codex\NaverNameSeoTracker\.git 폴더는 비어 있습니다.
- 즉, 아직 정상적인 Git 저장소가 아닙니다.

2. 먼저 해야 할 일
- 새 저장소로 시작: git init
- 기존 GitHub 저장소 연결:
  git init
  git remote add origin https://github.com/USER/REPO.git
  git branch -M main

3. 배치파일 설명
- 깃허브_받기.bat: 현재 브랜치 pull --rebase
